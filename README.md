# Titanic Data Visualization – InternCircle Task 2

## Overview
A data visualization project based on the Titanic dataset using Python, Matplotlib, and Seaborn.

## Visualizations
- Survival count bar chart
- Survival by gender
- Survival rate by passenger class
- Age distribution histogram
- Fare distribution box plot
- Age distribution by survival box plot
- Age vs. fare scatter plot
- Numerical correlation heatmap

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## Dataset
Titanic CSV dataset loaded from a public GitHub dataset source.

## Objective
To communicate patterns and relationships in the Titanic data through clear and informative visualizations.
